# noam — סביבת העבודה של נועם (מפתח/ת האפליקציות)

סביבת העבודה של נועם לבניית אפליקציות ווב מלאות (Vite + React + Firebase):
קבצי עבודה, טיוטות ארכיטקטורה ותבניות קוד. התוצר המוגמר נשמר ב-`Output/<slug>/`
שבשורש הפרויקט.

החלוקה מול עומר: עומר בונה **דפי נחיתה סטטיים**; נועם בונה **אפליקציות** — עם
מסד נתונים, התחברות, הרשאות ונתונים בזמן אמת.
