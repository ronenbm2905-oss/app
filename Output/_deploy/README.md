# חבילות מוכנות להעלאה (Netlify Drop)

התיקייה הזו מכילה קובצי ZIP ארוזים של דפי נחיתה, מוכנים לגרירה/העלאה
ל-https://app.netlify.com/drop — כדי שלא צריך לארוז ידנית.

- `hashiluv-hamenatzeach-netlify.zip` — דף "השילוב המנצח".
  מכיל `index.html` + `assets/` בלבד (בלי README), כך שנטליפיי מגיש את הדף מהשורש.
  המקור: `Output/hashiluv-hamenatzeach/`.

**לרענן אחרי שינוי בדף:** לארוז מחדש את תוכן `Output/hashiluv-hamenatzeach/`
(רק `index.html` + `assets/`) ולדרוס את ה-ZIP כאן.
