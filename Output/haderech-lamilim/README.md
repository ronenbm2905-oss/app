# הדרך למילים — אפליקציית משחק

אפליקציית ווב חינוכית לילדים 2–8 לשיח רגשי, מבוססת על ערכת הקלפים הפיזית **"הדרך למילים"** מאת דורית בן מאיר ([doritplus.co.il](https://doritplus.co.il)). 24 קלפי איורים, 8 מצבי משחק, ממשק קולי בעברית — הכול רץ בצד-לקוח בלבד (בלי שרת, בלי התחברות, בלי איסוף מידע).

## דרישות
- **Node.js 18+** (פותח על Node 24).
- דפדפן מודרני: Chrome/Edge 90+ או Safari 15+.
- להקראה קולית: קול עברי (`he-IL`) מותקן במערכת ההפעלה. בהיעדרו האפליקציה לא נשברת — הטקסט תמיד מוצג על המסך.

## הרצה מקומית
```bash
npm install
npm run dev
```
השרת עולה על http://localhost:5174 .

## בנייה לפרודקשן
```bash
npm run build
```
התוצר נכתב לתיקיית `dist/` (סטטי, נכסים בנתיב יחסי `base: './'` — נפתח מכל תת-נתיב או static host).

תצוגה מקדימה של ה-build:
```bash
npm run preview
```

## פרישה (Deploy)
האפליקציה סטטית לחלוטין — כל static host מתאים:
- **Netlify Drop:** גררו את תיקיית `dist/` ל-[app.netlify.com/drop](https://app.netlify.com/drop).
- או כל שירות אחר (Vercel / GitHub Pages / Firebase Hosting) — מגישים את תוכן `dist/`.

> ⚠️ אין צורך בשרת, במסד נתונים או במשתני סביבה.

## מבנה הפרויקט
```
src/
  data/cards.js          24 הקלפים: שם, משפט מנוקד, מיפוי רגש, 4 שאלות שיח, נתיב תמונה
  components/
    Home.jsx             מסך הבית — רשת 8 מצבי המשחק
    games/               8 מצבי המשחק (התאמות, זיכרון, מצא-זוג, שיח, מה-הרגש, פאזל, צביעה)
    ui/                  רכיבים משותפים (כפתור, קלף, משוב, כותרת מסך, כפתור הקראה, מסך ניצחון)
  hooks/
    useSpeech.js         עטיפת Web Speech API (TTS עברית) עם fallback חינני
    useSound.js          צלילי משוב מסונתזים (Web Audio API, בלי קבצי אודיו)
  utils/                 shuffle, בניית חתיכות פאזל (SVG bezier)
public/cards/            24 תמונות הקלפים (card-01.jpg … card-24.jpg)
scripts/                 חילוץ התמונות מה-PDF (ראה למטה)
```

## חילוץ תמונות הקלפים (מקור הנתונים)
תמונות הקלפים חולצו מ-`Briefs/haderech/klafim_drawings_bizua_shtanz.pdf` (עמודים אי-זוגיים) דרך Node — **לא Python** (הסביבה בלי Python/OpenCV):
```bash
npm run extract:images
```
הסקריפט מרנדר את עמודי ה-PDF ל-PNG וחותך שוליים לבנים. התמונות כבר קיימות ב-`public/cards/`; הרצה חוזרת נדרשת רק אם מחליפים את ה-PDF המקורי.

## נגישות ופרטיות
- נבנה לפי ת"י 5568 (WCAG 2.0 AA): טקסט חלופי בכל התמונות, תוויות ARIA, משוב מוקרא (`aria-live`), ניגודיות תקינה, יעדי-מגע גדולים, ותצוגה ניתנת להגדלה (zoom).
- **אין איסוף מידע:** אין התחברות, אין עוגיות, אין analytics, אין קריאות רשת חיצוניות (למעט טעינת פונט מ-Google Fonts — לשקול self-hosting).
- **הצהרת נגישות פורמלית** טרם פורסמה — טיוטה ב-`../../adi/Outputs/haderech-lamilim-accessibility-statement.md` (טעונה השלמת פרטי רכז נגישות ובירור פטור-עוסק).

## הערה על התוכן
המשפטים המנוקדים הם התוכן המקורי של דורית בן מאיר. **שמות הקלפים, מיפוי הרגשות, ו-4 שאלות השיח לכל קלף** עברו עידון אך **ממתינים לאישור סופי של היוצרת** לפני שימוש ציבורי מלא.
