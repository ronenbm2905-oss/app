# Basketball Scheduler — מדריך המאמן (Onboarding למאמנים)

## Overview
מדריך עצמאי למאמני קרית אונו: **איך לשמור את האפליקציה במסך הבית של הטלפון** (PWA — אין חנות
אפליקציות) ו**איך לתפעל אותה** מצד המאמן. נכתב כי האפליקציה
([[basketball-scheduler-cloud-migration]]) חיה ב-`basketball-schedule-f0f57.web.app` והמאמנים
מקבלים אליה גישה בלי הסבר מסודר.

התוצר: קובץ HTML עצמאי אחד — `Output/basketball-scheduler/public/guide.html`. הוא יושב ב-`public/`
בכוונה, כדי שייצא ב-`npm run build` ל-`dist/` ויוגש מ-Firebase Hosting בכתובת קבועה
`/guide.html`. ה-rewrite הגורף ב-`firebase.json` (`"source": "**"`) לא מפריע — Hosting מגיש קובץ
סטטי קיים לפני שהוא מפעיל rewrite.

מבנה המדריך (ששת השלבים תואמים את הסדר שבו מאמן באמת נתקל בדברים): שמירה למסך הבית (אייפון/
אנדרואיד בנפרד) → כניסה עם Google → מסך הבית והמשבצות → תצוגת מאמן לעומק כולל שליחת הדוח
השבועי לוואטסאפ → איך תדע שמשהו השתנה → שש תקלות נפוצות. **מסך "שחקנים" לא מוזכר במדריך**
(החלטת רונן 18.8 — מסתירים אותו ממאמנים).
