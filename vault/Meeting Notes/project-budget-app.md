# Project Budget App — ניהול תקציב פרויקט (פינסקר 9)

## Overview
מערכת לניהול תקציב, תזרים תשלומים, פנקס חשבוניות ומנות החזר מרשות (מס רכוש) בפרויקטי
בנייה/שיפוץ. נבנתה סביב **פינסקר 9 תל אביב** (תקציב 9,256,727 ₪ כולל מע״מ, 20 חודשי
תזרים אוג׳26–מרץ׳28, החזר מס רכוש 4,780,215 ₪), אבל **רב-פרויקטית מהיום הראשון**.
התוצר: `Output/project-budget/` — Vite + React 18 + Tailwind (JavaScript), fallback מקומי
ל-localStorage, עברית/RTL. עקרון-העל: **פנקס חשבוניות אחד, שלושה מבטים** — תזרים,
תקציב מול ביצוע והחזרי הרשות הם שלושה חתכים של אותה חשבונית, לא שלוש טבלאות.
נבנה בפרוסות; פרוסה 0 (מודל + ייבוא + מנועים) ופרוסה 1 (פנקס + מנות) **shipped**,
כולל מסכי תזרים ותקציב מול ביצוע, קלט מקורות מימון ולוח תשלומים, ייבוא התשלומים ששולמו
בפועל, וגיבוי/שחזור. **שכבת הענן והתפקידים** (owner/manager/viewer לפי מייל, כללי Firestore
שנבדקו מול אמולטור) כתובה — אך טרם רצה מול Firebase חי. סריקת AI טרם נבנתה.
