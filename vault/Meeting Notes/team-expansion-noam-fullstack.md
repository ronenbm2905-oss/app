# הרחבת הצוות — נועם, מפתח/ת אפליקציות (Full-Stack)

## Overview
הוספת חבר צוות חמישי: **נועם**, מפתח/ת אפליקציות Full-Stack, לצד עומר (דפי נחיתה
סטטיים). הרקע: החברה כבר עברה בפועל מדפי נחיתה לאפליקציות — עומר בנה את
[[basketball-scheduler-cloud-migration]] (Vite+React+Firebase) שחורג מהגדרת התפקיד
שלו ("HTML/CSS/JS סטטי, בלי build"), והיה צורך במישהו שזה הליבה שלו. נועם מוגדר על
אותו סטאק שכבר הוכיח את עצמו: **Vite + React 18 + Tailwind v3 + Firebase
(Firestore/Auth/Hosting), JavaScript**, עם fallback מקומי (localStorage), realtime
(`onSnapshot`), הרשאות, RTL/i18n ו-QA עצמי (build + dev + דפדפן).

**החלוקה עומר↔נועם:** דף אחד שמוכר וממיר → עומר. משתמשים / נתונים שנשמרים / כניסה /
כמה מסכים → נועם.

**עדכון (2026-07-21):** הנושא הזה הפך ללוג ההרחבה הכללי של הצוות. נוסף חבר צוות שישי:
**מאיה**, מנהלת המשרד (תפעול) — מיון תיבת דואר, טיוטות מייל, תיאום פגישות, תזכורות
ומעקבים. שונה משאר הצוות: היא **תפעול, לא ייצור**. חוק ברזל שלה: **מכינה — לא
שולחת** (עקבי עם טל שמכין ולא מפרסם, ונועם שמכין deploy ולא מריץ). עובדת דרך חיבור
ה-Gmail (טיוטות בלבד — אין כלי שליחה, בכוונה) ומנגנון המשימות המתוזמנות; כל
שליחה/אישור/קבלת-הזמנה עוברת אישור מפורש של המשתמש ברמת דורית.
