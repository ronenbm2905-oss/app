# Basketball Scheduler — המרה לאפליקציית ענן

## Overview
המרה של `scheduler_1.html` (אפליקציית React בקובץ בודד, localStorage בלבד) לאפליקציית ענן
מלאה תחת `Output/basketball-scheduler/`. הסטאק: **Vite + React 18 + Tailwind v3 + lucide-react +
SheetJS + Firebase (Firestore/Auth/Hosting)**, JavaScript (לא TS). הכלי מנהל מערכת שעות של מועדון
כדורסל: קבוצות/מאמנים/אולמות, אימונים, אילוצים, ייבוא משחקים מהאיגוד (xlsx), לוח שבועי להדפסה/PDF,
תצוגת מאמן, **דו"ח שעות חודשי לפי מאמן** (יחידה=1.5ש', מנטרל ספורטתרפיה/יורם),
**רשימת שחקנים לפי קבוצה** (שם/טלפון/ת.לידה/מידות/מס' גופייה, עם ייבוא מאקסל + תבנית),
ו**ייצוא הסעות למשחקי חוץ** (רשימת משחקי חוץ+כתובות לשבוע, אקסל+תמונה, עם שעת יציאה מומלצת).
מ-23.8.2026 נוספה שכבת **תיעוד מקצועי של המאמן** בתת-אוספים נפרדים: הערות אחרי משחק, ו**מערך
אימון** דיגיטלי שנאמן לטופס הנייר — ומ-24.8 גם **שרטוט מגרש** לכל תרגיל (סמנים + עט חופשי על
חצי מגרש או מגרש שלם), שנשמר כגיאומטריה ולא כתמונה.
מ-27.8.2026 יש גם מסך **זמינות** — לוח חודשי שבו מנהל מסמן חוסר זמינות ב**תאריך בודד**
(`absences`, יום שלם או טווח שעות). זו הישות המתוארכת שהשלימה את `constraints`, שהוא חוזר לפי
יום בשבוע בלבד; הסימון עולה כאזהרה אדומה על אותם אימונים בלוח השבועי ובתצוגת המאמן.
מ-30.8.2026 למסך הזה **שני נושאים**: מאמן שלא זמין, ו**אולם שנלקח** לתאריך מסוים. אותה רשומה,
אותו מסך, מתג מאמן/אולם — ההבדל הוא בטווח הפגיעה (מאמן מרוקן את האימונים שלו, אולם סגור מרוקן
את של כולם, כולל משחקי בית) ובפרטיות (סיבת אולם מוצגת לכולם; סיבת מאמן לא).
מ-1.9.2026 יש גם **הערכת התקדמות חציונית**: פעמיים בעונה כותב מאמן פסקה על כל שחקן בקבוצתו,
ורק המנהל המקצועי והכותב קוראים אותה — בתת-אוסף `playerProgress`, ובאכיפת `firestore.rules`
ולא בהסתרה במסך. זו הרשומה הראשונה בפרויקט ש**אינה שומרת את שם השחקן** אלא מזהה בלבד.
מבוסס על מפרט `basketball_spec_v2.docx` (14 סעיפים). עיקרון: **המרה, לא כתיבה מחדש** —
כל הלוגיקה הועברה מהמקור ואורגנה למבנה הקבצים של סעיף 11 במפרט.

מאפיין מפתח שנבחר: **fallback מקומי** — אם אין Firebase config, האפליקציה רצה במצב localStorage
(כולם "admin"); ברגע שמוגדר `.env` עם מפתחות → מצב ענן עם `onSnapshot`, כניסת Google, והרשאות
מנהל/מאמן לפי מערך `admins` במסמך `clubs/main`.

**מודל זמן (מ-28.7.2026):** אימונים הם **מבוססי-שבוע** — לכל session שדה `weekOf` (יום ראשון של
השבוע), עם ניווט שבועות (`WeekNav`), "שכפל שבוע קודם", ועמודת "סה"כ שבוע". לא תבנית חוזרת: כל שבוע
עומד בפני עצמו (בחירת המשתמש). אילוצים נשארים כללים חוצי-שבועות.
מ-1.9.2026 יש להעתקה גם **רזולוציית שורה**: כפתור העתקה על כל שורה בלוח השבועי לוקח את
אימוני הקבוצה של אותו שבוע ומדביק אותם בשבוע אחר (`utils/rowCopy.js`) — אותה עסקה כמו
"שכפל שבוע קודם", ברזולוציה שבה מנהל באמת עובד: שורה אחת זזה, השאר לא.
