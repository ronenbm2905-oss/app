# Property Management App — בנייה

## Overview
אפליקציית ניהול נכסים לבעלים פרטיים (נכס בודד עד 100 דירות), שלושה סוגי משתמשים (בעלים / פורטל דייר / צוות תחזוקה). Vite + React + Firebase עם fallback מקומי, i18n עברית/אנגלית + RTL/LTR, מדינה+מטבע פר-נכס, תשואה כשדה מחושב. האפיון המקורי חולץ מ-`property_app_spec.docx` ותויק ב-`Briefs/property-management-app-spec.md`. נבנה **בפרוסות**; פרוסה 1 (צד הבעלים, הזנה ידנית), **פרוסה 2** (3 תפקידים — owner/tenant/maintenance — עם רסטרקטורינג לתת-אוספים ובידוד ב-firestore/storage rules), ו**פרוסה 3** (סריקת מסמכים ב-Claude דרך Cloud Function + מנוע תזכורות client-side) הושלמו. התוצר: `Output/property-management/`. שער הפרטיות (עדי) מתועד בנפרד ב-[[property-management-privacy-by-design]] — חוסם לפני deploy.
