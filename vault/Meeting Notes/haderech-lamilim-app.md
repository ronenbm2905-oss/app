# אפליקציית "הדרך למילים" (Haderech Lamilim)

## Overview
אפליקציית ווב חינוכית לילדים 2–8 (+ מנחים: הורים/מטפלים/מחנכים), מבוססת על ערכת
**24 קלפי איורים** פיזית מאת דורית בן מאיר. בעברית/RTL, כולה client-side (בלי שרת,
בלי login, בלי DB). כוללת **8 מצבי משחק** (התאמות, זיכרון תמונה+משפט, זיכרון מתחת
לגיל 6, משחק 2–4, שיח עם קלף, "מה הרגש?", פאזל SVG, דפי צביעה), ממשק קולי (Web Speech
API עברית + Web Audio API לצלילים מסונתזים). הבריף המלא ב-`Briefs/haderech/`
(`haderech_lamilim_spec.docx` + 2 PDF מקור: ציורים וטקסט + `ISHUR.pdf`). התוצר נבנה
ע"י **נועם** ב-`Output/haderech-lamilim/`. שונה מנושא המצגת [[derech-hamilim-lecture-deck]]
(אותו מותג, תוצר אחר).

## Open Questions
- **תוכן מיוצר-AI שדורש אישור אנושי** — השמות, מיפוי הרגש, ו-4 השאלות לכל קלף **לא היו
  בקבצי המקור**; נועם יצר ברירת-מחדל סבירה מנושא הקלף + מאגר שאלות גנרי מ-ISHUR.pdf.
  **שירה עברה עידון (2026-07-27)**; עדיין **חייב אישור סופי של דורית בן מאיר (היוצרת)** —
  בפרט: מיפוי הרגש ב-5 קלפים דו-משמעיים (1/14/16/17/24) מול האיורים, והשמות החדשים
  לקלפים 1/24. המשפטים המנוקדים כן חולצו מה-PDF ולא נגעו בהם.
- **איזון "מה הרגש?"** — התפלגות הרגשות מוטה חיובי (happy×12, excited×7, sad×4, angry×1).
  angry מופיע רק בקלף 12. להחלטת היוצרת אם לאזן.
- **לשון זכר בכל השאלות** — עקבי, אך אם רוצים ניטרלי לבנים/בנות — החלטת היוצרת.
- **סטייה מהאפיון: Vite+React במקום קובץ HTML בודד** — רונן בחר במפורש. `base:'./'` +
  `server.port:5174 strictPort` הוגדרו. אומת שהבנייה עובדת בדב; לאמת גם פתיחה סטטית של `dist/`.
- **דפי צביעה בלי OpenCV** — edge detection יֵעשה ב-canvas בדפדפן (Sobel/threshold ב-JS)
  בזמן ריצה, לא Python. לאמת איכות ויזואלית.
- **קול עברי ב-Web Speech API** — תלוי בקול he-IL מותקן במערכת; צריך fallback חינני
  (הצגת טקסט) אם אין. לבדוק בפועל.
- **תיקוני שער עדי לפני deploy** — **M2 (ניגודיות) ו-M3-קוד (הסרת חסימת zoom ב-viewport)
  בוצעו ואומתו חי ע"י דורית (2026-07-27).** נותר: **M1** — אישור דורית בן מאיר על התוכן
  מיוצר-AI + הכרעת 5 מיפויי-הרגש (הצעות דורית מוכנות, ראה למטה); **M3-הצהרה** — פרסום הצהרת
  הנגישות (טיוטה מוכנה ב-`adi/Outputs/`) + בירור פטור-עוסק (⚖️ עו"ד). קניין רוחני **נסגר**
  (בעלות משותפת רונן+דורית — אמירת רונן בצ'אט; R1: לתעד בכתב, המלצה לא חוסם).
- **הצעת מיפוי רגש ל-5 הקלפים הדו-משמעיים (דורית עיינה באיורים, 2026-07-27)** — 1: מתרגש→**שמח**
  (חיוך שליו); 14: **שמח** (לשמור); 16: מתרגש→**שמח** (חיוך רגוע); 17: **שמח** אך פרח בלי פנים —
  לשקול להחריג מ"מה הרגש?"; 24: **שמח** (לשמור). כולן **הצעות לאישור דורית בן מאיר** — cards.js לא שונה.
