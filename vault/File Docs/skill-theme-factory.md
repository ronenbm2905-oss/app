אפשר גם לייצר ערכה חדשה על בסיס תיאור. ליאור שולף כשאין מערכת ויזואלית מאיתי;
כשיש מפרט מאיתי — **הוא קודם**.

(אין tofu) אבל הן נראות גנריות בעברית. טבלת תחליפים עבריים בנספח. הפלטה נשארת;
