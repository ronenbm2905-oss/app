הנחיות לכיוון ויזואלי ייחודי: לגזור פלטה וטיפוגרפיה מהנושא עצמו במקום מברירות מחדל,
לבנות מבנה שמקודד מידע ולא מקשט, ולהשתמש באנימציה במשורה. המטרה המפורשת — דף שלא
נקרא כתבנית AI. איתי שולף אותו בתחילת כל בקשת עיצוב, עומר לפני כתיבת ה-CSS.

**נספח מקומי** בסוף הקובץ: RTL כברירת מחדל, פונטים עבריים (Heebo/Assistant/Rubik/
Frank Ruhl Libre), `line-height` מינימלי בעברית, וניגודיות ת"י 5568.
