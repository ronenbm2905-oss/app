# agent-tal

**קובץ:** `.claude/agents/tal.md`
**משויך ל:** טל — הפרסום. **מוגדר** (לא עוד שלד). סוגר את השרשרת.

בונה **חבילת קמפיין מלאה** סביב דף הנחיתה של עומר — **מכין בלבד, לא מפרסם דרך API**.
ערוצים: **Google Ads + Meta** (גנרי להרחבה). כולל: אסטרטגיה+תקציב, טירגוט (מילות
מפתח/קהלים), קופי פרסומי בתוך מגבלות תווים עם 2-3 וריאציות והתאמת-מסר לדף, ותוכנית
מעקב/UTM שמתחברת ל-hooks של עומר (`data-cta`, `data-event`, placeholder אנליטיקס).

מחקר רשת: כן (WebSearch/WebFetch) למילות מפתח/מתחרים/מפרטי פלטפורמות. קלט: בריף +
קופי (`shira/Outputs/`) + הדף (`Output/`). פלט: `tal/Outputs/<date>-<slug>-campaign.md`
+ תיעוד ב-`vault/Campaign Log/`.
