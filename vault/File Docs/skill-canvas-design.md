# skill-canvas-design

**קובץ:** `.claude/skills/canvas-design/SKILL.md`
**משויך ל:** איתי (המעצב).
**מקור:** [anthropics/skills](https://github.com/anthropics/skills), Apache 2.0.

יצירת עיצוב ויזואלי **סטטי** (`.png` / `.pdf`) בשני שלבים: קודם פילוסופיית עיצוב
כקובץ `.md`, ואז ביטוי שלה על קנבס. לפוסטר, מודעה לדפוס, כרזה, גרפיקה לרשתות.

**הגבול מול הסקיל `design`** (מתועד בנספח): `design` מייצר קנבס HTML אינטראקטיבי
שהופך אחר כך לקוד של עומר/נועם; `canvas-design` מייצר קובץ סטטי שנשלח או מודפס.

**אזהרה:** `canvas-fonts/` מכילה 81 פונטים לטיניים (5.5MB) ואף אחד מהם אינו עברי —
שימוש בהם לטקסט עברי ייתן ריבועים. לעברית יש לטעון פונט עברי במפורש, ולוודא
כיווניות RTL ידנית (הקנבס לא מטפל בה לבד).
