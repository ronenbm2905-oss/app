**הגבול מול הסקיל `design`** (מתועד בנספח): `design` מייצר קנבס HTML אינטראקטיבי
שהופך אחר כך לקוד של עומר/נועם; `canvas-design` מייצר קובץ סטטי שנשלח או מודפס.

**`canvas-fonts/` הוחלפה בסט עברי** (29.8.2026): 81 הפונטים הלטיניים המקוריים הוסרו,
ובמקומם 36 קבצים ב-20 משפחות — כל אחד נבדק ל-27/27 אותיות עבריות **וגם** כיסוי לטיני
מלא, כלומר הסט מטפל בשתי השפות. הקטלוג לפי קטגוריה ב-`canvas-fonts/FONTS.md`,
והרישיונות (SIL OFL 1.1, אחד למשפחה) ב-`canvas-fonts/licenses/`.
