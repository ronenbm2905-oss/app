# config-env-example

**קובץ:** `.env.example`
**משויך ל:** קונפיגורציה (כל הצוות).

תבנית משתני הסביבה: `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, ומפתחות פר-עובד
(תמונות לאיתי, פרסום/analytics לטל) — כולם ריקים. מעתיקים ל-`.env` וממלאים.
ה-`.env` עצמו לא נשמר ב-git.
