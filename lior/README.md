# lior — סביבת העבודה של ליאור (בונה/ת המצגות)

סביבת העבודה של ליאור לבניית מצגות: טיוטות סטוריליין, רשימות שקפים ותבניות דק.
התוצר המוגמר נשמר ב-`Output/<slug>/` שבשורש הפרויקט (`<slug>.pptx` + `storyline.md`).

ליאור בונה דרך ה-skill `pptx`, עם קופי משירה, מערכת ויזואלית ותמונות מאיתי
(`gpt-image-gen`), וגרפים מ-`dataviz`. חוק ברזל: **סיפור לפני שקפים** — קשת סיפורית
מוגדרת לפני שנבנה שקף אחד.
