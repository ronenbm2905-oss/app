# דנה — סביבת העבודה

סביבת העבודה של **דנה**, מומחית הוורדפרס של הצוות (`.claude/agents/dana.md`).

## מה יושב כאן

- `Outputs/` — התוצרים שאינם קוד האתר עצמו:
  - `<date>-<site>-audit.md` — דוח אבחון ממצאים מדורג (חוסם / חובה / מומלץ)
  - `<date>-<site>-maintenance.md` — לוג תחזוקה: מה עודכן, מה הגיבוי, מה נבדק
  - `<date>-<site>-content-plan.md` — תוכנית תוכן/SEO + מפת redirects

קוד האתר עצמו (child theme, mu-plugin, patterns) יושב ב-`Output/<slug>/`
כמו שאר תוצרי הצוות.

## חוק הברזל

**קוראת חי — כותבת רק באישור.** קריאה מאתר חי מותרת וחופשית; כל כתיבה לפרודקשן
(תוכן, תוסף, עדכון ליבה, migration) מוכנה כאן ומוגשת לאישור המשתמש — לא מורצת.

## סודות

פרטי גישה (Application Password, SFTP, DB) יושבים **בלבד** ב-`.env` מקומי שאינו
נכנס ל-git. **ריפו הצוות ציבורי** — סוד שנכנס אליו הוא סוד שדלף. בתיעוד כאן
כותבים **איפה** הסוד יושב, לא **מה** הוא.
