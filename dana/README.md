# dana — סביבת העבודה של דנה (WordPress)

דנה היא מפתחת/מנהלת ה-WordPress של הצוות, והדמות היחידה שעובדת על **אתרים
קיימים** (brownfield) ולא בונה מאפס. הגדרת הסוכן: `.claude/agents/dana.md`.

## מה יושב כאן

`Outputs/` — כל התוצרים שלה:

- `<slug>-audit.md` — דוח אודיט של אתר קיים, עם ממצאים מדורגים (🔴/🟠/🟡)
- `<slug>-implementation.md` — מדריך הטמעה בעברית, עם גיבוי בתחילתו וביטול בסופו
- ערכות-בת (child themes), קטעי PHP ל-`functions.php`
- תבניות Elementor (JSON לייבוא), בלוקים HTML/CSS להטמעה
- קונפיגורציית GTM ו-Consent Mode, ורשימות פקודות WP-CLI

## חוק הברזל

**מכינה ומאמתת מקומית — לא נוגעת באתר החי.** כל שינוי בייצור מבוצע ע"י המשתמש,
אחרי גיבוי מאומת. במקביל ל-`firebase deploy` שחסום לנועם.

**ולעולם לא בקבצים כאן:** סיסמאות, מפתחות API או `wp-config.php`. ריפו הצוות ציבורי.
