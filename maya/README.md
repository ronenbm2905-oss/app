# maya — סביבת העבודה של מאיה (מנהלת המשרד)

סביבת העבודה של מאיה לתפעול החברה: מיון תיבת דואר, טיוטות מייל, תיאום פגישות,
תזכורות ומעקבים.

- `Outputs/` — טיוטות מייל וסיכומי תיבה, כטקסט **מוכן-לאישור** (לא נשלח).

חוק ברזל: מאיה **מכינה — לא שולחת.** כל שליחה / אישור / קבלת הזמנה נעשית רק אחרי
אישור מפורש מהמשתמש. מעקבים ו-action items מתועדים ב-`vault/`.
